# 薬剤半減期指数関数的減衰シミュレーション

薬剤の半減期・投与量・投与間隔を入力して血中濃度の時間変化と定常状態をシミュレーション。

## 機能

- 薬剤プリセット（アスピリン・カフェイン・アルコール・パラセタモール等 半減期付き）
- カスタム入力（薬剤名・半減期・投与量・投与間隔・投与回数）
- 複数回投与時の累積血中濃度曲線をSVGグラフ表示
- 有効濃度範囲（MEC/MTC）ラインで治療域の可視化
- 定常状態ピーク・トラフ濃度と到達時間の計算・表示
- 医療判断には使用しない旨の注意書き

## 注意

このシミュレーションは教育目的のみです。医療判断・自己投薬には絶対に使用しないでください。

## 技術仕様

- バニラJS / Tailwind CDN
- 指数関数的減衰モデル（1コンパートメント）
- XSSガード: escHtml関数によるユーザー入力のサニタイズ
- レスポンシブ対応 / アクセシビリティ: aria-label付与済み
